# Instrucciones de Desarrollo de SIMVA

## Preferencias del Repositorio de GitHub
- **Rama de Trabajo**: Todos los envíos, commits, exportaciones y sincronizaciones de código para este repositorio de GitHub deben estar dirigidos a la rama `develop` (en lugar de `main`).
- El usuario gestiona la exportación y sincronización final a través del menú de Configuración de AI Studio, por lo que toda preparación de código debe tener esto en cuenta.
